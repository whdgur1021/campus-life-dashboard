# 🎓 Campus Life Dashboard

대학생 캠퍼스 라이프 데이터를 분석하고 시각화하는 Streamlit 대시보드 웹 애플리케이션입니다.

## 📌 주요 기능
- **데이터 로드 및 결측치 처리**: CSV 파일 업로드 및 비정상/결측 데이터 자동 정제
- **학과별 필터링**: 선택한 학과에 맞춘 평균 학교생활 만족도 계산
- **생활 습관 및 만족도 시각화**: 학과별 평균 생활 습관 막대그래프 및 만족도 상관관계 산점도
- **한줄의견 텍스트 분석**: 학과별 주요 키워드 상위 10개 추출 및 긍정/부정 감성 단어 빈도 분석
